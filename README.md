# Austin Map Lab 

Data snapshot: 6 October 2026. The archive contains 1,034,217 mapped reports across twenty categories. Report CSVs are stored per issue and year as gzip files; modern browsers decompress them locally. Use a current Chrome, Firefox, Edge, or Safari.

Austin 311 Public Data: https://data.austintexas.gov/d/xwdj-i9he
Street Centerline: https://data.austintexas.gov/d/m5w3-uea6
Lakes and Rivers: https://data.austintexas.gov/d/9hn3-nb38

Leaflet 1.9.4 is bundled. Its BSD license is included in LEAFLET-LICENSE.txt.
